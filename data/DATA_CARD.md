# Data card: LG 18650HG2 (processed)

Generated by `data/prepare.py` from the raw files. Do not edit by hand.

## Source

P. Kollmeyer, M. Naguib, M. Skells, *LG 18650HG2 Li-ion Battery Data*, Mendeley Data, V2, 2020. doi:10.17632/b5mj79w5w9.2. Licence CC BY 4.0. Per the dataset description: a new 3 Ah LG HG2 cell, tested at McMaster University in an 8 cu.ft. thermal chamber on a Digatron tester with 0.1 % of full scale voltage and current accuracy. Only the `.mat` files are used; per the dataset readme the `.csv` files hold the same data.

## Sign convention

Raw files report discharge current as **negative**. Detected from the first sustained current segment of every C/20, 0.5C, 1C and 2C discharge file, each required to lower the voltage by at least 0.3 V. Processed files use **positive = discharge**.

## Columns (Parquet)

| Column | Unit | Description |
|---|---|---|
| `time_s` | s | Test time from the raw `Time` column, re-zeroed at the first kept sample |
| `voltage_v` | V | Cell terminal voltage (raw `Voltage`) |
| `current_a` | A | Cell current (raw `Current`), converted so that positive = discharge |
| `ah` | Ah | Tester amp-hour counter (raw `Ah`), sign converted so that positive = net discharge |
| `power_w` | W | Tester power (raw `Power`), sign converted with current |
| `temp_degc` | degC | Battery temperature as reported by the tester (raw `Battery_Temp_degC`) |
| `soc_ref` | fraction | Drive cycles only. Reference SoC: 1 - (ah - ah[0]) / C20 discharge capacity at that ambient temperature |

Rows with a duplicate `Time` value are dropped (first kept) in every file; they would otherwise give zero-length time steps.

Not loaded: `Wh` (uint8 with one constant value in the files inspected) and `TimeStamp` (wall-clock string, redundant with `Time`).

## Capacity and reference SoC

Capacity at each ambient temperature is the tester Ah counter change over the C/20 discharge (and the following C/20 charge). Drive cycles start after a CC-CV charge to 4.2 V, so the reference SoC starts at 1.0 and follows the tester Ah counter, normalised by the C/20 discharge capacity at the same ambient temperature. The full-charge start is checked per cycle: the file just before it must be a charge that reached the 4.2 V CV limit (column `start_check` in `index.csv`). The Ah counter was preferred over integrating the logged current because it continues through logging gaps; on the drive cycles the two agree to a median maximum difference of about 1 mAh.
